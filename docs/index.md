## About HamWAN Memphis Metro

HamWAN Memphis Metro is a 501(c)3 non-profit organization building and operating an experimental high-speed data network for use by licensed amateur radio operators. Our network provides internet connectivity and serves the emergency preparedness community in the greater Memphis metropolitan area.

The network operates on amateur radio frequencies and is designed to be resilient, providing backup communications during emergencies when traditional infrastructure may be unavailable.
